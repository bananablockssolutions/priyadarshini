# M-1 spike log

Environments:
- **Cloud sandbox:** WordPress 7.1.4 on SQLite (PHP 8.3), no WooCommerce. SQLite timings are indicative only.
- **Live Hostinger site (empty, used as staging), 2026-11-12:** PHP 8.2.35, MariaDB 11.8.9, WP-CLI 2.12.0, WooCommerce 11.3.0, run over SSH. Output saved on the owner's laptop in `build\dev\results\run-2026-11-12.txt`.

**Run on real MariaDB with real WooCommerce, 2026-11-12:** spike1 8/8, spike7 41/41, spike_alloc 14/14, blocks1 36/36, no FAIL lines. Spike 1 query median 2.2 ms (limit 100 ms) on 200 artisans. This confirms the schema, the artisan query, the review repository, the allocation storage and the follow API on MySQL-family databases and with WooCommerce active. It does NOT cover cart, checkout, Store API, Router navigation or any browser behaviour on the live site.
